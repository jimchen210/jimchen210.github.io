一、我们如何收集和使用您的个人信息

1. 我们收集哪些信息

我们不会主动收集您的任何个人信息。

您在使用本应用时，为了生成命盘和分析报告，您需要主动输入以下信息。这些信息全部仅保存在您的设备本地（使用 Apple 的 Core Data 框架），不会被上传到任何云端服务器：

  • 姓名：您为命盘起的名称，便于识别和管理。
  • 性别。
  • 出生日期：支持公历或农历。
  • 出生地点（可选）：用于排盘参考。

2. 我们如何使用这些信息

  • 您输入的信息仅用于在您的设备本地生成命盘排盘、命理分析和心理学综合报告。
  • 所有分析运算均在您的设备本地完成，不会传输到任何外部服务器。
  • 我们不会将您的信息用于任何其他目的。

3. 我们获取的设备权限

权限名称功能目的
使用网络访问配置文件和加载法律政策页面
获取网络状态判断网络是否可用，优化配置加载
写入存储导出备份 JSON 文件或保存 PDF 报告

4. 第三方服务说明

本应用未集成任何第三方分析、广告或追踪 SDK。所有功能均不依赖外部服务，您的数据不会与任何第三方共享。

二、数据存储方式与保护

1. 存储方式

  • 所有命盘数据、分析报告、付费解锁记录等，均存储在您设备的本地数据库中。
  • 您可以通过「导出备份 (JSON)」功能将数据导出为 JSON 文件，该文件同样仅保存在您的设备本地。
  • 您可以通过「清除所有数据」功能，随时永久删除所有本地数据。
  • 我们不会将您的数据传输至境外。

2. 数据保留期限

  • 您的数据保留在您的设备本地，直至您主动删除。
  • 当您删除应用或清除数据后，所有本地数据将被永久删除。

3. 数据安全措施

  • 数据存储在 iOS 系统提供的安全沙盒中，其他应用无法访问。
  • 不连接任何第三方服务器，避免网络传输带来的数据泄露风险。
  • 我们采取符合业界标准的安全措施来保护您的个人信息安全。

三、信息共享与披露

我们不会以任何形式出售、交易或转让您的个人信息。

由于数据仅存储在您的设备本地，我们技术上无法访问、查看或分享您的数据。

共享、转让、公开披露的例外

以下情形中，共享、转让、公开披露您的个人信息无需事先征得您的授权同意：

  • 与国家安全、国防安全有关的；
  • 与公共安全、公共卫生、重大公共利益有关的；
  • 与犯罪侦查、起诉、审判和判决执行有关的；
  • 出于维护您或其他个人的生命、财产重大合法权益但又很难得到本人同意的；
  • 您自行向社会公众公开的个人信息；
  • 从合法公开披露的信息中收集个人信息的，如合法的新闻报道、政府信息公开渠道。

四、您如何管理您的个人信息

我们非常重视您对个人信息的管理，并尽全力保护您对自己信息的查看、修改、删除权利。

  • 查看：您可以在「我的」页面查看已添加的所有命盘列表。
  • 修改：您可以在「我的」页面点击具体命盘，修改姓名、性别、出生日期等信息。
  • 删除：您可以在「我的」页面左滑删除单个命盘，或在「设置」→「数据备份与恢复」→「清除所有数据」中永久删除所有数据。
  • 导出数据：您可以在「设置」→「数据备份与恢复」→「导出备份 (JSON)」中导出所有命盘数据（JSON 格式），该文件仅保存在您的设备本地。
  • 导出报告：您可以在 App 内将生成的各类命理报告导出为 PDF 文件，该文件仅保存在您的设备本地，供您个人查阅或分享。
  • 撤回授权：您可以通过卸载本应用来撤回全部授权。卸载后，所有本地数据将被永久删除。

五、未成年人的个人信息保护

本应用不面向 13 周岁以下儿童。我们不会故意收集儿童的个人信息。

如果您是 13-18 周岁的未成年人，建议您在父母或其他法定监护人的指导下使用本应用。

如果我们发现自己在未获得可验证的监护人同意的情况下收集了未成年人的个人信息，将立即启动个人信息删除程序，并在合理期限内完成相关数据的删除工作。

  • 为给您提供更好的服务，本隐私政策可能会适时更新。
  • 未经您明确同意，我们不会限制您按照本隐私政策应享有的权利。
  • 对于重大变更，我们会通过应用内弹窗提示方式通知您。
  • 如您不同意更新内容，您仍可继续使用已有功能；但您将无法使用本次更新后新增或变更的功能。
